# Folder Pengumpulan

Buat folder dengan format `KELAS-NAMA` (contoh: `XI-PPLG-1-budi`), lalu isi dengan file `tugas-01.md`, `tugas-02.md`, dst.

Gunakan template berikut untuk setiap file:

```markdown
# Tugas XX – Judul Tugas
**Nama:** 
**Kelas:** 

**Link repo/commit:** https://github.com/...

## Screenshot
![hasil 1](link-gambar)
![hasil 2](link-gambar)

## Catatan / Kendala
- 
```
