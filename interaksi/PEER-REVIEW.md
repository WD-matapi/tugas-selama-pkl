# Peer Review Antar Siswa

Setiap siswa **minimal 4 kali** memberi review pada Pull Request teman selama 12 minggu (dihitung sebagai keaktifan).

## Cara
1. Buka tab **Pull requests** → pilih PR teman.
2. Klik **Files changed** / buka link repo → baca hasilnya.
3. Tulis komentar yang **sopan, spesifik, dan membangun**.

## Format Komentar
```
✅ Yang sudah bagus:
- ...

💡 Saran perbaikan:
- ...

❓ Pertanyaan:
- ...
```

## Yang bisa direview
- Struktur folder & penamaan
- Validasi & keamanan (CSRF, `.env`, password hash)
- Kerapian kode dan commit message
- Tampilan & kemudahan penggunaan
