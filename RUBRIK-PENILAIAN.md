# Rubrik Penilaian

Berlaku untuk setiap tugas (skor 0–100), lalu dikalikan bobot pada README.

| Aspek | Bobot | Kriteria |
|--|:--:|--|
| Fungsionalitas | 50% | Semua requirement tugas berjalan tanpa error |
| Kualitas kode | 20% | Penamaan rapi, struktur MVC benar, tidak ada kode berulang berlebihan |
| Git & dokumentasi | 15% | Commit jelas, README/instalasi ada, `.env` tidak ter-commit |
| Tampilan & UX | 10% | Rapi, konsisten, mudah dipakai |
| Ketepatan waktu | 5% | Dikumpulkan sebelum tenggat |

## Predikat Nilai Akhir
| Nilai | Predikat |
|:--:|--|
| 90–100 | Sangat Baik |
| 80–89 | Baik |
| 70–79 | Cukup |
| < 70 | Perlu Bimbingan (remedial) |
