# Panduan Absensi untuk Siswa

## Cara absen setiap minggu
1. Buka tab **Issues** di repo ini → **New issue** → pilih **📝 Absensi Mingguan** → *Get started*.
2. Isi semua kolom (nama, kelas, minggu, status, tugas, link bukti, ringkasan).
3. Klik **Submit new issue**. Bot akan membalas otomatis.
4. Guru memeriksa lalu memberi label **terverifikasi**. Cek status di [REKAP-ABSENSI.md](../REKAP-ABSENSI.md).

## Aturan
- Wajib **1x per minggu**, batas **Minggu 23.59 WIB**.
- Hanya akun GitHub yang terdaftar di `daftar-siswa.csv` yang dihitung. Hubungi guru bila namamu belum ada.
- Status **Mengerjakan tugas** wajib menyertakan **link bukti** (commit/repo) yang bisa dibuka guru.
- **Izin/Sakit** dicatat tetapi tidak dihitung sebagai hadir. Sampaikan alasan di ringkasan.
- Absensi tanpa bukti atau bukti tidak valid diberi label **ditolak**.
- Mengirim data palsu / bukti hasil menyalin teman dikenai pengurangan nilai keaktifan.

## Arti ikon di rekap
| Ikon | Arti |
|:--:|--|
| ✅ | Hadir, sudah diverifikasi guru |
| 🕓 | Terkirim, menunggu verifikasi |
| 📝 | Izin / sakit (terverifikasi) |
| – | Belum absen |
