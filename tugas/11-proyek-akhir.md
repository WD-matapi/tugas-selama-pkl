# 🏆 Proyek Akhir – Mini Aplikasi Berbasis Kasus PKL
**Minggu:** 11–12 | **Bobot:** 25% | **Level:** ⭐⭐⭐⭐

## Tujuan
Membangun aplikasi web utuh yang menyelesaikan **masalah nyata** (atau simulasi) dari tempat PKL, dengan menerapkan semua materi Tugas 01–10.

## Pilihan Topik
Pilih satu (atau usulkan topik sendiri dan minta persetujuan guru **sebelum minggu 11**):
1. Sistem Informasi Inventaris / Gudang
2. Aplikasi Absensi & Rekap Kehadiran
3. Sistem Helpdesk / Tiket Keluhan
4. Aplikasi Kasir (POS) Sederhana
5. Sistem Manajemen Proyek / To-Do Tim
6. Aplikasi Reservasi / Booking
7. Sistem Arsip Surat / Dokumen Digital
8. Topik lain sesuai kebutuhan tempat PKL

> ⚠️ **Etika data:** Jangan memakai data rahasia perusahaan. Gunakan data dummy.

## Spesifikasi Minimal
- [ ] Minimal **4 tabel** dengan relasi yang benar (ada minimal 1 many-to-many atau one-to-many)
- [ ] **Autentikasi** + minimal **2 role**
- [ ] **CRUD lengkap** dengan validasi (Form Request)
- [ ] **Upload file** (gambar/dokumen)
- [ ] **Pencarian + pagination**
- [ ] **Dashboard** berisi ringkasan data (jumlah, grafik sederhana, atau tabel terbaru)
- [ ] **Laporan** yang bisa dicetak/export (PDF/Excel/print)
- [ ] Seeder data dummy & akun demo
- [ ] Tampilan **responsif** (nyaman di HP)
- [ ] (Opsional) Endpoint API

## Dokumen yang Harus Dikumpulkan
1. **Proposal singkat** (1 halaman): latar belakang, fitur, pengguna, teknologi → `docs/proposal.md`
2. **ERD** → `docs/erd.png`
3. **README proyek**: deskripsi, fitur, cara instalasi, akun demo, screenshot
4. **Link repo GitHub** dengan riwayat commit yang konsisten (min. 15 commit)
5. **Video demo** 3–5 menit (link YouTube/Drive) atau presentasi langsung
6. (Opsional) **Link deploy** (hosting gratis / tunnel)

## Tahapan
| Minggu | Target |
|--|--|
